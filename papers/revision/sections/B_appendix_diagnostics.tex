\section{Legacy H100 diagnostic details}
\label{app:legacy-h100}

We reran the preserved legacy notebook pipeline on one NVIDIA H100 80GB HBM3.
This pipeline predates the revised Tight GBDN implementation; its GBDN+ row
evaluates only the relaxed legacy architecture.  For heterophily, every row
uses seed 25, official split column 0, normalized features, hidden width 64,
1,000 epochs, and validation-AUROC checkpoint selection.  Roman-empire and
Amazon-ratings use accuracy; Minesweeper, Tolokers, and Questions use macro
one-versus-rest ROC-AUC.  We recomputed every ROC-AUC entry from the archived
test probabilities using tie-aware average ranks because the legacy scalar
routine resolves equal scores by implementation-dependent sort order.

All 60 method--dataset artifacts were produced, but the rerun fails the
prespecified reproduction criterion.  Relative to the archived artifacts,
GBDN+ on Roman-empire changes by 0.2963 accuracy and H2GCN on Minesweeper by
0.0353 ROC-AUC.  The run also lacks the required CLI manifest.  Consequently,
\cref{tab:legacy-heterophily} establishes only that the legacy jobs executed
on the H100; it does not validate the implementations or their ordering.

The same legacy run produced two Peptides-func artifacts using the official
split objects, seed 25, hidden width 256, batch size 128, and 100 epochs.
Average precision was saved without test predictions, so it cannot be
independently recomputed.  The test values differ by $6.08\times10^{-5}$ and
therefore round to the same four-decimal value, while GBDN+ uses 5.15 times the
peak allocated CUDA memory of ChebNet at $K=10$.
